# P16 Label Desk

Локальный конструктор печатных полос для Behringer P16-HQ/P16-M. Работает без сборщика и сервера приложений: это обычные HTML, CSS и JavaScript.

## Запуск

Самый простой вариант — открыть `index.html` в браузере. Для поиска иконок через Iconify браузеру нужен доступ в интернет.

Если браузер ограничивает сетевые запросы из локальных файлов, запустить встроенный веб-сервер:

```bash
cd p16hq-labels/constructor
python3 -m http.server 8765 --bind 127.0.0.1
```

Затем открыть <http://127.0.0.1:8765/>.

## Возможности

- точная полоса 228 × 18 мм и лист A4 в альбомной ориентации;
- объединение соседних каналов в стереопары внутри групп по четыре;
- название и дополнительная мелкая подпись;
- композиции: иконка сверху, иконка слева, только текст или только иконка;
- оформление: цветная полоса сверху/снизу, полная или лёгкая заливка, рамка, только цвет иконки;
- автоматический контраст текста;
- несколько шрифтов, изменение размера текста и иконок;
- встроенный набор SVG-иконок и поиск по каталогу Iconify;
- автоматическое сохранение проекта в `localStorage`;
- импорт и экспорт JSON;
- экспорт одной полосы в SVG;
- печать до восьми полос на A4 с метками реза и контрольной линейкой 50 мм.

## Печать

В системном диалоге печати выбрать масштаб **100% / Actual size** и отключить `Fit to page`. Контрольная линейка на бумаге должна иметь длину ровно 50 мм.

## Иконки и лицензии

Встроенный набор использует [Phosphor Icons](https://phosphoricons.com/) 2.1.1 (MIT) и Font Awesome Free 6 (CC BY 4.0). Дополнительные иконки загружаются через Iconify; их лицензия зависит от выбранного набора и отображается в каталоге Iconify.
